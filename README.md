# Password Generator

A fast and efficient Python tool that generates all possible combinations of a given word or characters based on the length specified by the user. It can process and generate thousands of combinations in just a second and save the output directly into a `.txt` file for further analysis.

## Features
* **Lightning Fast:** Generates custom-length combinations in a fraction of a second.
* **Custom Length:** Allows the user to specify the exact combination length (e.g., 5, 10, etc.).
* **Auto-Save:** Automatically saves the generated output into a clean text file.
* **User-Friendly:** Simple command-line interface (CLI) built with Python.
